# মানহা স্মার্ট পরীক্ষা ব্যবস্থাপনা ও সিট প্ল্যান সিস্টেম (Manha Exam Management & Seat Plan System)

একটি পূর্ণাঙ্গ, আধুনিক ও স্বয়ংক্রিয় পরীক্ষা ব্যবস্থাপনা সফটওয়্যার। এর মাধ্যমে বিদ্যালয়ের আসন বিন্যাস (Seat Plan), কক্ষওয়ারী শিক্ষার্থী তালিকা, প্রবেশপত্র ও হাজিরা শিট, শিক্ষকদের সমবন্টনভিত্তিক সাইক্লিক ডিউটি রোস্টার এবং পরীক্ষা পরিচালনা বাজেট বিবরণী প্রস্তুত করা যায়।

---

## 🚀 প্রধান সুবিধাসমূহ (Key Features)

1. **শিক্ষার্থী ব্যবস্থাপনা ও এক্সেল আপলোড:**
   - এক ক্লিকে এক্সেল (Excel .xlsx/.xls) ফাইল থেকে রোল, নাম, শ্রেণী ও শাখা আপলোড।
   - ইনলাইন এডিট পেন্সিল ও মুছার সুবিধা।
   - স্বয়ংক্রিয় কলাম ডিটেকশন ও কাস্টম কলাম ম্যাপিং।

2. **কক্ষ ও বেঞ্চ বিন্যাস (Room & Bench Layout):**
   - প্রতি কক্ষে কলাম বা সারির সংখ্যা নির্ধারণ (২ বা ৩ কলাম)।
   - প্রতি বেঞ্চে শিক্ষার্থী সংখ্যা (১/২/৩ জন) এবং কলামওয়ারী বেঞ্চ সংখ্যা কনফিগারেশন।
   - জিকজ্যাক (Zig-Zag) ও রোল সিরিয়াল আসন বিন্যাস অ্যালগরিদম (পাশাপাশি একই শ্রেণীর শিক্ষার্থী না বসার নিয়ম)।

3. **শিক্ষক ও প্রত্যবেক্ষক ডিউটি রোস্টার (Invigilator Cyclic Roster):**
   - ১২ দিনের পূর্ণাঙ্গ পরীক্ষার রুটিনের সাথে শিক্ষকদের সমবন্টনভিত্তিক সাইক্লিক রোস্টার।
   - প্রত্যবেক্ষক পরিবর্তন ও বদলি ডিউটি (Substitution) রেকর্ড ও ট্র্যাকিং।
   - শিক্ষক তালিকা ও রুটিন এডিট ও কাস্টমাইজেশন।

4. **আর্থিক বাজেট ও সম্মানী ব্যবস্থাপনা (Exam Expenses & Remuneration):**
   - পরীক্ষা পরিচালনা কমিটি ও প্রশাসন (প্রধান শিক্ষক, সহকারী প্রধান, আহ্বায়ক, সদস্য সচিব, সদস্য) সম্মানী তালিকা।
   - কক্ষ প্রত্যবেক্ষক শিক্ষক সম্মাননা হিসাব।
   - অফিস সহকারী, দপ্তরী ও কর্মচারীদের দিনভিত্তিক সম্মানী ও প্রাপ্য নির্ধারণ।
   - স্ট্যাম্প ও রাজস্ব রশিদ সম্বলিত মাস্টার বাজেট ও খরচ বিবরণী।

5. **প্রিন্ট ও রিপোর্ট (Print Templates):**
   - কক্ষওয়ারী ডেস্কে লাগানোর সিট স্লিপ (Desk Slips)।
   - গেটে বা দেওয়ালে লাগানোর নোটিশ বোর্ড সিট প্ল্যান।
   - বিষয়ভিত্তিক স্বাক্ষর ও হাজিরা শিট (Attendance Sheet)।
   - শিক্ষকদের সমবন্টন সাইক্লিক ডিউটি রোস্টার তালিকা।
   - শিক্ষক ও কর্মচারীদের রেভিনিউ স্ট্যাম্প সম্বলিত বিল ভাউচার।
   - পূর্ণাঙ্গ মাস্টার বাজেট বিবরণী (Master Statement)।

6. **ডেটা ব্যাকআপ ও অফলাইন PWA:**
   - সম্পূর্ণ পরীক্ষার ডেটা এক ক্লিকে JSON ফাইলে এক্সপোর্ট ও ইমপোর্ট।
   - কম্পিউটার বা মোবাইলে অফলাইন অ্যাপ (PWA) হিসেবে ইনস্টল করার সুবিধা।

## 🛠️ লোকাল কম্পিউটারে রান করার নিয়ম (How to Run Locally)

### প্রয়োজনীয় সফটওয়্যার:
- [Node.js](https://nodejs.org/) (সংস্করণ 18 বা তার বেশি)
- [npm](https://www.npmjs.com/) (Node.js এর সাথে স্বয়ংক্রিয়ভাবে ইনস্টল থাকে)

### ধাপসমূহ:

1. **জিপ ফাইলটি আনজিপ করুন:**
   ডাউনলোডকৃত `manha-exam-management-system.zip` ফাইলটি যেকোনো ফোল্ডারে এক্সট্র্যাক্ট (Extract) করুন।

2. **টার্মিনাল বা কমান্ড প্রম্পট খুলুন:**
   এক্সট্র্যাক্ট করা ফোল্ডারে গিয়ে টার্মিনাল বা কমান্ড প্রম্পট (CMD / PowerShell) ওপেন করুন।

3. **প্যাকেজসমূহ ইনস্টল করুন:**
   ```bash
   npm install
   ```

4. **ডেভেলপমেন্ট সার্ভার চালু করুন:**
   ```bash
   npm run dev
   ```

5. **ব্রাউজারে ওপেন করুন:**
   টার্মিনালে দেখানো লিংকে প্রবেশ করুন (সাধারণত `http://localhost:3000` বা `http://localhost:5173`)।

6. **প্রোডাকশন বিল্ড তৈরি করতে:**
   ```bash
   npm run build
   ```

## 🆕 সকাল/বিকাল শিফট সংস্করণ (বার্ষিক পরীক্ষা-২০২৬)

- **রুটিন:** প্রত্যবেক্ষক ও রোস্টার → "পরীক্ষার রুটিন (শিফটসহ)"। দিন × শ্রেণী ম্যাট্রিক্স, শ্রেণী→সকাল/বিকাল নির্ধারণ, শিফটের সময়।
- **ডিউটি রোস্টার:** প্রতি (তারিখ × শিফট) আলাদা; ঐ বেলায় ব্যবহৃত কক্ষেই ডিউটি; একই দিনে দুই বেলা একই শিক্ষক যথাসম্ভব এড়ানো; ডিউটি সংখ্যা সমান।
- **সিট প্ল্যান:** শিফট + উপস্থিত শ্রেণী-সেট অনুযায়ী আলাদা প্ল্যান (সকাল ৬ষ্ঠ+৮ম, বিকাল ৭ম+৯ম, বিকাল শুধু ৯ম)।
- **সিট নিয়ম ও পরিবর্তন:** কক্ষ ১০১-এ আসন-১ → ষষ্ঠ/পদ্মা/১–৩০, আসন-২ → অষ্টম/তিতাস/৮৫–৫৫ (উল্টো)। আসনে ক্লিক করে অদল-বদল, অটো/উল্টো/এলোমেলো মোড।
- **হাজিরা শিট:** শুধু ঐ শিফটের শ্রেণী ও সেই শ্রেণীর বিষয় দেখায়।
